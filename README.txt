Static official YouTube player page for embedding inside MoviesDrive TV.
Deploy these three files at one HTTPS origin; no Python server, API key, downloaded video or URL extractor is needed.
The TV passes only the public YouTube video ID and an ephemeral message-session token.
Local file-origin embeds timed out on the tested TV; this hosted-origin route is a prototype and not yet verified on TV.
Deployment and actual trailer playback/sound remain pending.
